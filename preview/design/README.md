## 修改内容

- 活动：品牌与一句标语、双专题主视觉、图标分类、重点日期与图文活动列表。Coffee Chat摄影与用户确认的大模型交流生成配图各自对应主题；保留演示标签、免费事实和原有分页、错误、空数据、分类接入限制。新图同时用于演示活动详情及资源方向预览，页面标注AI生成，不是真实活动现场或已上线的聊天功能。

- 连接：内容说明、三步申请流程与未开放状态，无提交、撮合结果或公开联系方式。
- 我的：身份验证区、参与入口说明；服务端权限、管理员入口条件原样保留，不生成模拟身份。
- 活动详情：主题封面、标题及元信息层级、内容段落与固定底部未开放提示。管理/编辑页面沿用同一套全局字体、表单及状态样式，未变更逻辑。
- 底部四个导航使用原生自定义tabBar，28px图标、14px标签、独立安全区；跟随真实页面更新选中项，切换失败不假装成功。

## 查看与复现

打开index.html查看六页，点击320/390切换宽度。可切换活动加载、空数据、失败、长标题、图片失败场景；活动详情链接和底部页面链接可以切换浏览器对照。其他原生操作在浏览器对照中不会调用云函数，不能在此验收登录或报名。

运行 node preview/design/build.cjs 从当前WXML/WXSS生成浏览器对照。build.cjs仅支持本项目用到的标签，不是通用小程序运行器。运行 node preview/design/render.cjs 使用本机Edge输出图标PNG及截图；这是开发工具，不是应用依赖。原SVG及许可证均保留，可本地复现。
